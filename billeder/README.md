# Portrætter af præsidenter

Læg et billede pr. præsident i denne mappe, så vises det ved "Valgt præsident" i kortet. Findes billedet ikke, vises en rund mærkat med initialer.

Filen skal hedde som herunder og være `.jpg`, `.png` eller `.webp`. Billedet beskæres rundt, så et portræt med ansigtet øverst i billedet fungerer bedst. Kvadratiske billeder på mindst 200 x 200 punkter er nok.
